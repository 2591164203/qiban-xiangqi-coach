# 棋伴 · Windows 象棋辅导

选定天天象棋网页版的棋盘区域后，自动读取画面，在独立窗口显示下一步建议、中文着法、三条候选变化和箭头。可开启自动模式，由程序点击我方棋子与目标交叉点。识别使用 VinXiangQi 模型，计算使用皮卡鱼；运行时在本机完成。

当前版本：0.5，Windows x64。修复大字体下的文字遮挡，以及短暂漏识别后自动模式被提前关闭的问题。已通过 99 项功能与集成检查，以及完整/浮窗、150% 字体缩放和两次实测中断的界面回归检查。新版连续在线对局仍待实测。

这是源码仓库。模型、引擎、SDK、缓存及运行包通过构建脚本准备，不提交到 Git。首次克隆后，在 Windows PowerShell 中运行：

```powershell
.\scripts\setup.ps1
.\scripts\build.ps1 -Publish
.\启动棋伴.cmd
```

应用源码使用 GPL-3.0；第三方资源各自保留原许可，见 [THIRD_PARTY.md](THIRD_PARTY.md)。

## 开始使用

1. 构建运行包后，双击项目根目录的 `启动棋伴.cmd`，也可运行 `dist/ChessCoach-v0.5/ChessCoach.exe`。窗口标题应包含 **v0.5**。独立包已包含 .NET 运行时。
2. 在浏览器中打开天天象棋网页版，进入要使用的棋盘。
3. 在棋伴中点击 **连接棋盘**，框入完整棋盘和全部棋子，可以包含外边框。按 Enter 确认后会立即预览并自动开始读屏，程序从图像中校准实际交叉点。
4. 首次确认 **当前行棋：红方 / 黑方**，核对重建棋盘和网页棋子是否一致。之后轮次会自动跟随，不用每步手动切换。改变轮次会重新建立同步；暂停后点击 **开始读屏** 恢复。
5. 连续三帧得到相同棋局后开始计算。正常走棋会自动更新轮次和提示。绿色箭头显示在棋伴自己的棋盘上，默认由你在网页里操作落子。

## 自动行棋

连接并同步后，先核对重建棋盘与网页一致，确认 **当前行棋**，再选择 **我执红方 / 我执黑方**，点击 **开启自动行棋**。这两个颜色设置含义不同：当前行棋是现在轮到谁，执棋颜色是程序替你操作哪一方。首次开启需由你确认轮次；程序不能只凭一张静止棋盘确定当前轮到谁。

完整界面和浮窗都保留自动开关。点击 **停止自动 · F8**，或在任意窗口按 **F8**，立即取消后续操作，继续保留读屏与建议。F8 注册失败时不会启用自动模式。程序关闭、暂停读屏、重新框选、手动校准或改变识别/行棋方设置都会关闭自动模式；重新启动程序默认关闭。

程序只在我方回合、局面已确认且识别置信度不低于 80% 时安排一步走法。点击前重新采集并识别两次，核对最新棋子、朝向、源点与目标点像素，以及目标窗口、屏幕坐标和遮挡；随后发送棋子与落点的两次鼠标点击。切换到其他应用、移动鼠标接管或窗口尺寸变化会中止该次操作。自动运行时保持浏览器棋盘可见。

发出点击后等待实际画面确认。连续三帧确认我方走法，或确认我方走法加对方合法回棋后，才允许安排下一步。未确认前不会重复点击。动画、漏识别、低置信度、窗口遮挡、暂时无法还原走棋顺序时，显示 **自动等待 · 画面恢复后继续**；恢复合法局面后，再连续确认三次且经过短暂退避，自动继续，无需再次点击开启。

八秒仍未确认落子结果时保留原待确认动作，继续等待画面恢复，不会清空动作或重发点击。尚未发送的走法若预检失败，会释放该动作、重新识别和分析后再复核。已确认画面会更新参考快照，避免中断时的选中高亮使后续复核一直失败。真正检测到人工接管、F8/手动停止、悔棋，或已发送的走法与可靠棋盘不符时会关闭自动；停止后不会因画面恢复而自行开启。持续无法合法还原的局面保持等待，可核对后手动校准。

自动模式操作当前棋局，不自动开始匹配或点击结算弹窗。进入另一局后请重新核对棋盘、行棋方与执棋颜色并启用。

程序会尝试移到采集区域旁，空间不足时自动切换 **浮窗模式**；点击 **展开** 返回完整界面。窗口默认置顶，可在“更多”中取消。保持网页棋盘完整可见；浏览器最小化、其他窗口遮挡实际棋盘、识别失败时会清除提示。若遮挡来自棋伴自身，会尝试移到棋盘旁。浏览器移动时选区会跟随并更新位置；浏览器尺寸或网页布局明显改变后需重新框选。

标题、说明、操作区按字体实际高度排列；完整界面和浮窗均支持换行。候选卡片保持适当高度，较矮窗口可滚动查看，不会挤压标题。程序初次打开或切换浮窗时会按屏幕工作区限制窗口尺寸。

快速回棋时，如果中间画面没被采到，程序会搜索到当前画面的合法走法，只有顺序可唯一确定时才自动补齐，最多补齐三步。单步悔棋可回到已记录的局面。无法唯一还原、新开局或跳转棋谱时会显示 **请核对局面**：对照“采集画面”、确认当前行棋方后，点击 **采用当前局面**。仅凭相同棋盘不能始终区分悔棋和合法重复，手动校准会重新建立历史。

## 界面选项

- **精准识别**：默认中模型；**快速识别**：小模型；**旋转兼容**：上游万能带旋转模型。红方在上或画面旋转时会结合像素归一化与朝向转换。
- **思考 / 秒**：默认 1 秒，可调整为 0.3～5 秒。总响应时间还包含采集、连续稳定帧和推理时间。
- **采集画面**：查看实际采集区域，与重建棋盘对照；绿色网格为校准后的交叉点。
- **识别设置**：调整朝向与识别模型，平时可保持收起。
- **更多 → 保存诊断**：将当前采集区域、已识别与已确认的 FEN、历史、同步状态和自动模式状态保存到程序旁的 `diagnostics` 文件夹。
- **更多 → 导入棋盘截图**：静态分析模式，尝试自动定位棋盘。
- **更多 → 复制当前 FEN**：复制已确认局面，便于定位问题。

评分为当前行棋方视角的引擎评估，不等于胜率。只有稳定且可从历史合法到达的局面能自动确认；补步有时间与搜索深度限制，无法确定时保留已确认历史并等待核对。重同步会重新建立历史，无法补回之前未录入的重复走棋记录。

## 已完成的验证

`docs/test-results.json` 记录 99 项通过的检查，包括规则、FEN、稳定帧、快回棋补步、重复历史、单步悔棋、初始轮次校正、错识别恢复、引擎取消、真实 MultiPV、图像识别和网页棋子像素回放。自动模式覆盖红黑/旋转/副屏坐标、单动作限制、回合去重、低置信度拒绝、延迟确认、异常暂停、停止后动作失效和图像遮挡复核。

0.5 回归用例来自用户日志中的两次真实中断：连续三帧漏掉静止的棋子后被拒绝，约 1.2 秒后恢复合法局面。测试确认漏识别不覆盖历史、不关闭自动，恢复后确认原走法。隐藏界面检查直接重放这两个案例，确认无需再次开启，并确认 F8 停止后不会自动恢复。另有 150% 字体与布局模拟、完整/浮窗渲染和文字边界检查。

保留 0.3 的同步修复：连续稳定等待期间双方已走完两步时，补齐可唯一还原的短序列，且自动更新界面行棋方。确认/拒绝/补步事件以及自动模式启停、发送与确认写入本地 `logs/tracking-*.jsonl`，相同识别状态去重。

图像回放使用实际腾讯 H5 的本地棋盘样本，把生成的点击坐标反算为落子，移动原有棋子像素模拟我方落子和快速回棋；跳过中间帧后，真实模型、同步器、自动确认器和皮卡鱼能够继续安排下一回合。这些检查没有向实际网页发送鼠标点击，也没有执行整局在线对局。`--capture-smoke` 的桌面采集工具已提供，本次未执行。

此版本仍需用实际网页验证连续落子同步，以及其他棋子皮肤、弹窗遮挡和不同显示缩放。单张实际棋盘画面通过不等于所有皮肤均兼容。

## 源码与构建

```powershell
.\scripts\setup.ps1
.\scripts\build.ps1
.\scripts\test.ps1 -Integration
.\scripts\build.ps1 -Publish
```

`setup.ps1` 获取固定版本的依赖，并按锁定哈希检查下载内容。SDK、NuGet 缓存和下载文件均放在项目目录。需要 Git、Windows 的 tar，以及可访问官方 GitHub、NuGet、微软下载源的网络。

目录：

- `src/ChessCoach`：Windows Forms 界面、采集、识别、棋局跟踪、规则与 UCI 引擎通信。
- `tests/ChessCoach.Tests`：无需额外测试框架的规则与真实集成测试。
- `vendor/VinXiangQi`：固定上游版本，编译时链接其 `YoloXiangQiModel.cs` 与识别库。
- `assets`：本地模型、引擎和测试样本。
- `dist/ChessCoach-v0.5`：当前独立运行包。旧版目录保留。
- `licenses`、`THIRD_PARTY.md`：来源、版本及第三方许可。

运行错误会写入程序旁的 `logs` 文件夹；正常运行无需账户、API Key 或云端图像服务。登录参数未写入项目。
