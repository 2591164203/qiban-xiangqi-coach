# v0.5 排查记录

## 已确认的中断原因

运行日志中确认了两次可重现的短暂识别失败，已将最小棋局整理为自动回归用例：

- 漏掉两个未移动的炮，拒绝局面并关闭自动；约 1.25 秒后已正确识别并接受 `e7g8`，但自动保持关闭。
- 漏掉一个未移动的兵，拒绝局面并关闭自动；约 1.24 秒后已正确识别并接受 `c7e7`，仍需手动开启。
- 落子前复核失败时，旧逻辑把尚未输入的失败也视为必须关闭自动。
- 其他窗口遮挡会导致连续采集失败。

## 修复

- 识别异常进入等待状态，保留用户的自动模式选择与已确认历史。恢复到合法棋盘后，连续确认三次并经过至少 600ms 退避，才继续安排动作。
- 尚未输入的预检失败可释放后重新识别；已经开始输入的动作保留到得到确认，不重发。八秒超时只标记延迟确认，后续恢复仍可确认原动作。
- 可靠帧刷新视觉参考，避免源棋子选中样式遗留造成永久复核失败。人工接管与 F8 仍关闭自动。
- 自身窗口遮挡时尝试移开，浏览器移动后更新采集区域位置。
- 标题、说明和工具栏按文字实际高度排版，替换固定像素高度与绝对文字坐标；参考缩放基准设为 96 DPI。候选区在矮窗口中滚动。

## 验证范围

99 项规则与真实模型/引擎集成检查。两个中断局面的规则级重放与界面级重放均通过；完整与浮窗布局检查包括 150% 字体/尺寸模拟，F8 后不再自行恢复。

离线回放不向网页发送鼠标输入；本次修改后的持续在线对局仍需实际使用验证。旧版运行包与用户日志均保留。
